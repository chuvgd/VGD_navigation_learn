# CPP编程基础

## 一. 内存四区

- 代码区：存放函数体的二进制代码，由操作系统进行管理
- 全局区：存放全局变量和静态变量以及常量
- 栈区：由编译器自动分配释放，存放函数的参数值，局部变量等
- 堆区：由程序员分配和释放，若程序员不释放，程序结束后由操作系统回收

**不同区域存放的数据，赋予不同的生命周期，给我们更大的灵活编程**

### 1.1 程序运行前：

 	在程序编译后，生成了exe可执行文件，未执行该程序前分为俩个区域：

- 代码区：存放cpu执行的机器指令

   	      代码区是共享的，代码区是只读的

- 全局区：全局变量，静态变量，还包含了常量区，字符串常量和其他常量（const）也存放在此

  **该区域的数据在程序结束后由操作系统释放**

### 1.2 程序运行后

栈区：

- 由编译器自动分配释放，存放函数的参数值，局部变量等
- **注意：不要返回局部变量的地址，栈区开辟的数据由编译器自动释放，栈区的相关数据是在相关块作用域运行结束之后自动释放**

堆区：

- 由程序员分配释放，若程序员不释放，**程序结束之后**由操作系统回收
- 在cpp中主要利用new在堆区开辟内存

### 1.3 new操作符号

- cpp中利用new操作符在堆区开辟数据

- 堆区开辟的数据，由程序员手动开辟，手动释放，释放利用操作符delete
- 语法：new 数据类型
- 利用new创建的数据，会返回该数据对应的类型的指针

### 6.枚举类型

枚举类型是cpp中的一种派生数据类型，它是由用户定义的若干枚举常量的集合

**如果一个变量只有几种可能的值，可以定义为枚举(enumeration)类型**

**所谓"枚举"是指将变量的值一一列举出来，变量的值只能在列举出来的值的范围内**

语法：

```cpp
enum 枚举名{
    标识符[=整型常量],
    标识符[=整型常量],
    ...
    标识符[=整型常量]
} 枚举变量；
```



如果枚举没有初始化，即省掉“=整型常数”时，则从第一个标识符开始

eg：

```cpp
enum color {red,green,blue} c;
c=blue;
```

在这个例子中，定义的是一个颜色枚举，变量c的类型为color，color是变量类型，这个变量类型具体的值是{red,green,blue}，最后这个c这个变量被赋值为“blue”



默认情况下，第一个名称的值是0，第二个名称的值是1，第三个名称的值是2，但是，也可以给名称赋予一个特殊的值，只需要添加一个初始值即可

```cpp
enum color {red,green=5,blue};
```

在这里，blue的值是6，因为默认的情况下，每个名称都会比它前面的一个名称大1，但是red依旧是0



### 7.类型转换

类型转换是将一个数据类型的值转换为另一种数据类型的值

cpp中有四种类型转化：静态转换，动态转换，常量转换和重新解释转换

- 静态转换（Static Cast）：

```
静态转换是一种将数据类型的值强制转换为另一种数据类型的值
静态转换通常用于比较类型相似的对象之间的转换，int转float
静态转换不进行任何运行时类型检查，因此可能导致运行时错误
编译时类型转换，主要用于已知安全的类型转换，比c语言风格的强制转换(T)value更加安全，具有明确的语义，编译时进行类型检查
```



```cpp
int i=10;
float f=static_cast<float>(i);
```

- 动态转换（Dynamic Cast）:

```
动态转换是cpp中用于在继承层次结构中进行向下转换的一种机制，动态转换通常用于将一个基类指针或者引用转换为派生类（子类）指针或者引用
动态转换在运行时进行类型检查，如果转换失败，对于指针类型会返回 nullptr，对于引用类型则会抛出std::bad_cast异常
动态转换是cpp运行时的类型转换，主要用于基类和派生类之间的转换，尤其是安全的向下转换（Base->Derived），必须使用多态（虚函数）
```

语法：

```cpp
dynamic_cast<目标类型>(表达式)
//目标类型：必须是指针或者引用类型
//表达式：需要转换的基类指针或者引用
```



- 常量转换（Const Cast）

```
常量转换用于将const类型的对象转换为非const类型对象
常量转换只能用于转换掉const属性，不能改变对象的类型
去除原本不是常量类型(const)变量的const属性的
```

```cpp
const int i=10;
int& r=const_cast<int&>(i); //常量转换，将const int转换为int，实际上是俩个变量了，变量类型也是不同
//const_cast我更偏向于转换同一个对象的属性，而不是将一个对象的属性转换为另一个对象的属性
//类型转换都应该强调的是：对于同一个对象的类型转换
//这个是错误的，详细见实例
```

- 重新解释转换（Reinterpret Cast）

```
重新解释转换将一个数据类型的值重新解释为另一个数据类型的值，通常用于在不同数据类型之间进行转换
重新解释转换不进行任何类型检查，因此可能会导致未定义行为
```

```cpp
int i=10;
float f = reinterpret_cast<float&>(i);//重新解释将int类型转换为float类型
```

**正确用法：指针与整数（或者其他类型）之间的转换**

```
补充：C语言风格转换((T)value)
c语言风格转换的可能同时应用了static_cast,const_cast和reinterpret_cast，容易引入隐患，不推荐使用
```



## 三. cpp变量类型

**变量其实只不过是程序可操作的存储区的名称**

**C++ 中每个变量都有指定的类型，类型决定了变量存储的大小和布局**

### 1. cpp中的变量类型

变量的定义就是告诉编译器在何处创建变量的存储，以及如何创建变量的存储

```cpp
int a=20;
//int--数据类型；a--变量名；20--变量值
```



### 2.cpp中变量的声明

```
当使用多个文件且只在其中一个文件中定义变量时（定义变量的文件在程序连接时是可用的），变量声明就显得非常有用
可以使用 extern 关键字在任何地方声明一个变量
虽然可以在 C++ 程序中多次声明一个变量，但变量只能在某个文件、函数或代码块中被定义一次
```

```
同样的，在函数声明时，提供一个函数名，而函数的实际定义则可以在任何地方进行
```

### 3.声明、定义、赋值的区别

一个变量的一生分三步：

- 声明（declaration）：只告诉编译器"有某个类型的变量叫这个名字"，不分配内存   ```extern int a;```
- 定义（definition）：真正创建变量、分配内存   ```int a;```
- 赋值（assignment）：往已经存在的变量里写入值，和"定义"无关   ```a = 10;```

**注意：定义 ≠ 赋值。** `int a;` 就是定义（造盒子），`a = 10;` 只是赋值（往盒子里放东西），变量在 `int a;` 那一行就已经诞生了。

**一句话记忆：定义是"造盒子"（`int a;`），赋值是"往盒子里放东西"（`a = 10;`），声明是"告诉你有这么个盒子，但盒子在别处"（`extern int a;`）**

### 4.extern关键字

`extern` 的作用是把一个"本该定义"的语句**降级成"只声明"**，不分配内存，承诺这个变量在别处（另一个 .cpp 文件）已经定义过了：

```cpp
extern int a;   // 只有 extern → 仅声明，不分配内存
int a;          // 没有 extern → 声明 + 定义，这里分配内存
```

**extern 是"先声明、后定义"的模式，但定义必须写在函数外面（文件作用域），不能写在函数内部。**

```
函数 { } 内部声明的变量是局部变量，它和外面的同名全局变量毫无关系，并且在它的作用域里会遮蔽（shadow）外面的那个
```

```cpp
// 错误：把定义写进函数里
extern int a;      // ① 文件作用域：声明全局变量 a（定义在别处）
int main() {
    int a;         // ② 函数作用域：创建局部变量 a，遮蔽了 ①，不是那个 extern 的定义！
}
```

上面代码里，`main` 里用的 `a` 是局部变量，extern 声明的那个全局 `a` 根本没被用到。

正确的"先声明后定义"写法：要么定义放函数外面，要么跨两个文件：

```cpp
// 同一个文件
extern int a;      // 声明
int a = 10;        // 定义（文件作用域，不是函数里）

// 或者跨两个文件
// a.cpp —— 定义（拥有这个变量，真正创建它）
int a = 10;
// b.cpp —— 声明并使用
extern int a;      // 声明：a 在 a.cpp 里定义
int main() {
    a = 20;        // 使用 a.cpp 里定义的那个 a
}
```

**定义和 extern 声明都必须写在函数外面（文件作用域）：**

- 定义 `int a = 10;` 如果写在函数里，就变成了局部变量（栈上，函数结束销毁），不是全局变量
- extern 声明也要写在函数外面；写在函数里是块作用域 extern，规则特殊、容易和局部变量混淆
- 规范做法：定义放某个 .cpp 的函数外面，extern 声明放函数外面（通常放头文件，让各个 .cpp 一起 include）
- 这样两者指向同一个全局变量，作用域都是文件作用域，还能被其他文件的 extern 借用

### 5.头文件中的声明与定义

头文件本身**既不是声明也不是定义**，它只是一段文本，`#include` 的本质是"把文件内容原样复制粘贴到当前 .cpp 里"。

**约定：头文件里放声明，定义放 .cpp。** 因为一个头文件通常被多个 .cpp 同时包含，如果里面写的是定义，每个包含它的 .cpp 都会各生成一份定义，链接时就会报错 `multiple definition`。

| 内容 | 是声明还是定义 | 能否放头文件 |
|------|--------------|-------------|
| `extern int a;` | 声明 | 能 |
| `int a;` | 定义 | 不能（重复定义报错） |
| `const int a = 5;` | 定义 | 能（内部链接） |
| `int f(int);` | 声明（函数原型） | 能 |
| `int f(int){...}` | 定义（有函数体） | 不能（除非 inline） |
| `class Foo {...};` | 类定义 | 能（不占内存） |

**判断标准：定义 = 要真正分配内存的。** 函数看有没有函数体 `{ }`：有 `{}` 是定义，以 `;` 结尾是声明。类定义（`class Foo {...};`）不分配内存，所以安全且通常必须放头文件。

例外——本身就是定义但放头文件安全：

- 类的定义   ```class Foo { ... };```
- inline 函数/变量：允许多个 .cpp 各一份，链接器不报错
- const / constexpr 变量：默认内部链接，每个 .cpp 各有一份副本
- 模板：必须在头文件，编译器在使用处实例化

### 6.multiple definition链接错误

编译分两步：

```
编译阶段：每个 .cpp 各自独立 → 生成各自的 .o（各干各的，互不打扰）
链接阶段：把若干个 .o 合到一起 → 生成一个可执行文件（此阶段才检查有没有重名符号）
```

`multiple definition` 发生在**链接阶段**，把多个 .o 拼成**同一个**可执行文件时，发现里面有两个同名的全局符号才报错。

```bash
g++ a.cpp b.cpp -o program   # a.o 和 b.o 里各有一个 a，拼一起 → 冲突报错
```

**报错条件：同一个可执行文件里，有多个 .o 各自带了同名定义。**

如果最后链成**不同的可执行文件**，每个文件内部只有一个定义，就不会报错：

```bash
g++ a.cpp -o program1   # program1 里只有一个 a，正常
g++ b.cpp -o program2   # program2 里只有一个 a，也正常
```

**本质：这个错误是"一次链接的范围内出现了重复"，而不是"整个项目里重复"——只要同名定义不进同一个最终的二进制，就没事。**

### 7.cpp中的左值和右值

- 左值：指向内存位置的**表达式**被称为左值表达式，**左值可以出现在赋值号的左边或者右边**
- 右值：术语右值指的是存储在内存中某些地址的**数值**，右值是**不能对其进行赋值的表达式**，也就是说，右值可以出现在赋值号的右边，但是不能出现在赋值号的左边

```cpp
int g = 20;
//变量是左值，因此可以出现在赋值号的左边
//数值型的字面量是右值，因此不能被赋值，不能出现在赋值号的左边
```

```cpp
10 = 20;
//无效语句，会生成编译时错误
```

注意：**左值实际上是能取到地址的表达式/名字，不是内存本身**

```
左值：有名字，有稳定内存地址，能取地址
eg. a,arr[0],*p,引用r等
```

```
右值：10,a+b的结果，函数返回的临时对象(按值返回)等
```



## 四.指针

### 1. 指针基本概念

作用：通过指针间接访问内存

- 内存编号从0开始记录，一般用16进制
- 可以利用指针变量保存地址

**指针就是一个地址**

指针定义的语法：

```cpp
数据类型* 指针变量名
//数据类型* 就是指的是数据的地址
```

### 2.指针所占内存空间

**指针也是一种数据类型，也会占内存空间**

- 在32位操作系统下：占用4个字节空间
- 64位操作系统下：占用8个字节空间

### 3.空指针

- 空指针用于给指针变量进行初始化
- 空指针是不可以进行访问的

```
空指针是指针变量指向内存中编号为0的空间
```

### 4.野指针

野指针：指针变量指向非法的内存空间

**空指针和野指针都不是我们申请的内存空间，无法进行访问**

### 5.const修饰指针

- const修饰指针 ——常量指针

```cpp
const int* p = &a;
//常量指针：指针指向可以修改但是指针指向的值不可以修改
```



- const修饰常量 ——指针常量

```cpp
int* const p = &a;
//指针常量：指针的指向不可以修改，指针指向的值可以修改
```



- const即修饰指针，又修饰常量

```cpp
const int* const p = &a;
//指针指向和指针指向的值都是不可以修改的
```

### 6.指针与数组

目的：指针去访问数组中的元素

### 7.指针与函数

- 利用指针作函数参数，可以修改实参的值

## 八.引用

### 1.引用的基本使用

作用：给变量起别名

语法：

```cpp
数据类型 &别名 = 原名
```

### 2.注意事项

- 引用必须初始化

```cpp
int a = 10;
int &b;//错误
int &b = a;//必须定义即初始化
```



- 引用在初始化后，不可以改变

```cpp
int a = 10;
int &b = a;
int c = 20;
int &b = c;//错误，初始化之后就不可以改变了
```

### 3. 引用做函数参数

作用：函数传参时，可以利用引用让形参修饰实参

优点：可以简化指针修改实参

### 4. 引用做函数返回值

作用：引用是可以作为函数的返回值存在的

注意：**不要返回局部变量的引用**

用法：函数的调用作为左值

### 5.引用的本质

本质：**引用的本质在cpp内部实现是一个指针常量**

tips：指针常量：修饰的是常量——指向不可以改变，但是指向的值可以改变

**这里再理解一下有关指针常量和常量指针**：

- 指针：两层含义——第一层：指针变量（即p），存放指向的地址值；第二层：指向的地址值所对应的数据（即int*）

```cpp
int a = 10;
int* p = &a;
```

- 指针常量：const修饰在指针变量前，不能修改指针的指向（指向即存放的地址）——指针变量存放的地址是常量，即只可读不能修改

```cpp
int a = 10;
int b = 10;
int* const p = &a;
p = &b;//错误，因为不能对指针指向进行修改
*p = 20;
```

- 常量指针：const修饰在指针类型前，不能修改指向的地址值所对应的数据——指针类型更像是一种对数据解析和指针步长的协议，对指针类型进行const，指针变量存放的地址值所对应的数据是常量，即只可读不能修改

```cpp
int a = 10;
int b = 10;
const int* p = &a;
p = &b;
*p = 20//错误，因为不能对指向地址所对应的数据进行修改
```

### 3. cpp类访问修饰符

数据封装是核心概念之一，简单来说，把数据藏起来，只开放必要的接口给外界使用，以保证数据的安全

控制谁能看到这些数据，cpp提供了三个关键字，称为访问修饰符：

- public（公有）
- private（私有）
- protected（受保护）

```
public:所有人可以访问（类内部，子类，外部代码）；对外提供的接口函数（API）
protected：你和你的孩子可以访问（类内部，子类）；仅限于家族内部（继承体系）使用的函数
private：只有自己可以访问（仅限于本类内部）；核心数据，不想被随意修改的变量
```

**注意：如果不写任何修饰符，cpp类成员默认是private（私有）的**

继承中的访问权限的变化：

```cpp
class B : public(protected/private) A
```

**重点：降级原则**

继承方式决定了父类成员在子类中的最高权限

```
父类成员原权限 	public 继承 (最常用) 	protected 继承 	 private 继承
public 			保持 public 			   降级为 protected   降级为 private
protected 		保持 protected 		   保持 protected     降级为 private
private 		不可访问 				  不可访问 			 不可访问
```

**注：不可访问是指的是子类代码无法直接使用该变量，但是变量仍然存在于内存中**

**继承方式决定"再往下、再对外"的可见性，不影响"子类自己能不能用它"**

### 4.构造函数和析构函数

类的构造函数是类的一种特殊的成员函数，它会在每次创建类的新对象时**自动执行**

若没有显式定义构造函数，编译器会自动生成一个不执行任何操作的默认构造函数

带参数的构造函数：一般用于给成员变量赋初始值

使用初始化列表来初始化字段：

```
cpp推荐使用成员初始化来初始化成员变量，它的语法是在构造函数参数列表后面加冒号（：），然后写成员变量名（初始值）
```

```
与在构造函数中不同的是：初始化列表在函数体之前就完成了成员变量的初始化，而函数体内赋值是先默认构造，再进行赋值，多了一步。对于const成员，引用成员以及没有默认构造函数的对象成员来说，初始化列表是唯一初始化的方式
```

```
const成员：const对象一旦构造完成就不能再被赋值，而进入构造函数体时成员已经被“默认构造”了，此时赋值违法
引用成员：引用必须在定义时绑定到对象，之后永远不能再改绑；构造函数中写时给引用的目标赋值，而不是绑定
没有默认构造函数的对象成员：如果不写初始化列表，编译器会尝试用默认构造函数去初始化它；但是该类没有默认构造函数，编译直接失败
```

**注意：初始化列表中各成员的初始化顺序由它们在类中的声明顺序决定的，而非书写顺序，建议保持一致**

**const和引用相关的成员一定要注意去进行构造前（创建对象前）就初始化！！！否则会出现未定义行为！！！**

这里再补充一点：在继承中使用初始化列表

```
情景：父类只声明了带参数的构造函数
在这种情况下，要特别注意到——因为父类只有带参的构造函数，如果子类构造函数没有显式地调用父类的带参构造函数，则会报错，所以必须显式调用，关于构造函数的显式调用，必须先初始化构造父类，再初始化构造子类
```

```cpp
#include <iostream>
using namespace std;

class animal{
   protected:
    	int height;
    	int weight;
   public:
    	animal(int height,int weight){
			this -> height = height;
            this -> weight = weight;
            cout<<"animal的带参构造函数被调用"<<endl;
        }
    	virtual ~animal(){
			cout<<"animal的析构函数被调用"<<endl;
        }
};

class fish : public animal{
    public:
    fish():animal(100,200)//初始化列表中先显式调用父类的构造函数
    {
        cout<<"fish的构造函数被调用"<<endl;
    }
    virtual ~fish(){
		cout<<"fish的析构函数被调用"<<endl;
    }
};

int main(int argc,char* argv[]){
    animal* fish_obj = new fish();
    delete fish_obj;
    return 0;
}
```

析构函数是在对象的生命周期结束时（离开作用域或者被delete时）自动执行，用于释放对象占用的资源

析构函数**不会返回任何值，也不能带有任何参数，**每个类只能有一个析构函数

###  5.拷贝构造函数

拷贝构造函数是使用同一类中之前创建的对象来初始化新创建的对象，通常用于：

- 通过使用另一个同类型的对象来初始化新创建的对象
- 复制对象把它作为参数传递给函数
- 复制对象，并从函数返回这个对象

如果在类中没有定义的拷贝构造函数，编译器会自行定义一个

如果类带有指针变量，并有动态内存分配，则它必须有一个拷贝构造函数

```cpp
classname(const classname &obj){
    构造函数主体
}
```

这里的obj是一个对象引用，该对象是用于初始化另一个对象

### 6.深入理解一下拷贝构造函数

前言：如果一个类中什么成员都没有，简称为空类

空类中编译器会自动生成以下6个默认成员函数：

- 初始化：构造函数
- 清理：析构函数
- 拷贝：拷贝构造是使用同类对象初始化创建对象
- 赋值重载：主要是把一个对象赋值给另一个对象
- 取地址重载：主要是普通对象和const对象取地址，这两个少会自己实现

拷贝构造函数接受一个同类对象作为参数，并按照该对象的数据成员的值来创建新的对象

用途：

- 创建对象时，使用同类已有对象的值来初始化新对象
- 以值传递的方式将对象传递给函数
- 以值返回的方式从函数返回

```cpp
classname(const classname &obj){
    拷贝构造函数的实现
};
```

obj是要拷贝的对象，拷贝构造函数的工作原理是将obj的数据成员的值复制给新创建的对象——独立，修改一个对象的数据成员的值不会影响另一个对象的数据成员

**默认的拷贝构造函数是浅拷贝**，即简单地将原对象的值复制给对象的数据成员，如果类中包含指针类型的数据成员，需要自己定义拷贝构造函数进行深拷贝，确保指针指向的对象也被复制

其相关特征：

- 拷贝构造函数是构造函数的一个重载形式
- 拷贝构造函数的参数只有一个且必须是类类型对象的引用，使用传值方式编译器直接报错，因为会引发无穷递归调用

若没有显式定义，编译器会生成默认的拷贝构造函数，**默认拷贝构造函数对象按照内存存储按字节序完成拷贝，这种拷贝叫浅拷贝，或者叫值拷贝**

**和构造函数不同，构造函数内置类型不会初始化，拷贝构造函数会初始化**

在学习深拷贝之前，我们需要特别地学习一下**c库函数-malloc()**

```
描述：
c库函数void* mallloc(size_t size)分配所需要的内存空间(动态分配的内存，需要手动释放，堆上数据)，并返回一个指向它的指针

声明：
void* malloc(size_t size)

参数:
size——内存块大小，以字节为单位

返回值：
该函数返回一个指针，指向已分配大小的内存，如果请求失败，返回NULL
```

**注意：类中如果没涉及资源申请时，拷贝构造函数是否写都可以；一旦涉及到资源申请时，则拷贝构造函数是一定要进行写的，否则就会发生浅拷贝**

使用场景：

- 使用已存在对象创建新对象
- 函数参数类型为类类型对象
- 函数返回值类型为类类型对象

tips：为了提高程序效率，一般对象传参时，尽量使用引用类型，返回时根据实际场景，能用引用尽量使用引用

```cpp
Date d2(d1);
//等价于
Date d2 = d1;
```

### 7.友元函数

类的友元函数是定义在类外部，但有权访问类的所有私有成员和保护成员，尽管友元函数的原型有在类的定义中出现过，**但是友元函数并不是成员函数**

- 友元可以是一个函数，该函数被称为友元函数
- 友元也可以是一个类，该类被称为友元类——在这种情况下，这个类及其所有成员都是友员

如果要声明函数为一个类的友元，需要在类定义中该函数原型前使用关键字**friend**

```cpp
class Box{
    double width;
    public:
    	double length;
    	friend void printWidth(Box box);
    	void setWidth(double wid);
};
```

声明类ClassTwo的所有成员函数作为类ClassOne的友元

```cpp
friend class ClassTwo;
```

```
友元函数没有this指针，传入参数时有三种情况：
- 要访问非static成员时，需要对象做参数；
- 要访问static成员或者全局变量时，则不需要对象做参数；
- 如果做参数的对象是全局对象，不需要通过对象或者指针
```

```cpp
class INTEGRE{
    frined void print(const INTEGRE& obj);//声明友元函数
};

void print(const INTEGRE& obj){
    //函数体
}

int main(){
    INTEGRE obj;
    print(obj);//直接调用
}
```

### 8.友元类

在cpp中，友员类是一个类与另外一个类的特殊类关系

在类A的**友元类**B中，可以直接访问A类的私有成员和受保护成员

- B是A的好朋友，B可以访问所有

语法：

```cpp
class Student
{
    private:
    	//声明StudentCaculate类是Student类的友元类
    	//在StudentCaculate类中可以访问Student类中的私有成员
    	friend class StudentCaculate;
}
```

- 单向性：友元类关系是单项的，声明B是另一个A类的友元类，B可以访问A所有成员，但是A不能访问B的私有和保护成员
- 继承性：友元类关系不具有继承性，即子类不能直接继承父类的友元类（友元类不能访问其子类）
- 作用：作为某个类数据操作辅助类；作为多个类之间传递信息的辅助类

### 9.内联函数

如果一个函数是内联的，那么在编译时，编译器会把该函数的**代码副本**放置在每个调用该函数的地方

对内联函数进行任何修改，都需要重新编译函数所有的客户端，因为编译器需要重新更换一次所有的代码，否则仍然使用的是旧函数

**关键字：inline**

在调用函数之前需要对函数进行定义

内联函数的机制：编译器将程序中出现的内联函数的调用表达式用内联函数的函数体进行替换，而对于其他函数，都是在运行的时候才被替换——本质是空间换时间的节省，但是这个空间开销不宜过大

**在类定义中的定义的函数都是内联函数，即使没有inline说明符**

```cpp
#include <iostream>
using namespace std;

inline int Max(int x,int y){
    return (x>y)?x:y;
}

int main(){
    std::cout<<"Max(20,10):"<<Max(20,10)<<std::endl;
    std::cout<<"Max(0,200):"<<Max(0,200)<<std::endl;
    std::cout<<"Max(100,1010):"<<Max(100,1010)<<std::endl;
    
    return 0;
}
```

### 10.this指针

this指针是一个特殊的指针，它指向当前对象的实例

**每一个对象都能通过this指针来访问自己的地址**

this是一个隐藏的指针，可以在类的成员函数中使用，它可以用来指向调用对象

当一个对象的成员函数被调用时，编译器会隐式地传递该对象的地址作为this指针

友元函数没有this指针，因为友元不是类的成员，只有成员函数才有this指针



**深入再去探讨一下this指针：**

每个非静态成员函数只会诞生一份函数实例，也就是说多个同类型的对象会共用一块代码——引入了“这一块代码是如何区分哪个对象调用自己的呢”

特殊对象指针——this指针；**this指针指向被调用的成员函数所属的对象**，this指针是隐含每一个非静态成员函数的一种指针，this指针不需要定义

this指针的用途：

- 当形式参数和成员变量同名，可用this指针来区分
- 在类的非静态成员函数中返回对象本身，可以使用return *this

this指针的本质——常量指针常量

this指针的本质：const Type* const pointer;

它存储了**调用它对象的地址**，并且不可被修改，这样成员函数才知道自己修改的成员函数是哪个对象的

```
date.SetMonth(9)<=>SetMonth(&date,9),this指针帮助了完成了这一转换，使得this指针指向了调用对象date
```

this指针的特点：

- 只能在成员函数中使用，在全局函数，静态成员函数中都不能使用this

  （this始终指向当前对象，静态成员属于类）

- this指针是在**成员函数的开始前构造**，并在成员函数结束后清除（和函数的其他参数的生命周期一样）

- this指针会因为编译器不同而有不同的存储位置，可能是栈，寄存器或者全局变量

- 关于this指针的一个经典问答：

```
当你进入一个房子后，你可以看见桌子、椅子、地板等，但是房子的全貌 ，你看不到了; 　　
对于一个对象（也就是类的实例）来说，你可以看到它的成员函数、成员变量，但是看不到对象本身了;
所以有了this指针，它时时刻刻指向你这个对象本身
```

### 11.指向类的指针

一个指向cpp类的指针与指向结构的指针类似，访问指向类的指针的成员，需要使用成员访问运算符->，就像访问指向结构的指针一样，需要对指针进行初始化

指向类的指针指向一个类的对象，与普通指针相似，**指向类的指针可以用于访问对象的成员变量和成员函数**

### 12.静态成员

static关键字，当我们声明类的成员为静态时，这意味着无论我们创建多少个类的对象，静态成员都只有一个副本

```cpp
class Runoob{
    public:
    	static int runoob_age; ——静态成员
        int runnob_users;——非静态成员
    public:
    	func(){
            int runoob_local;——局部变量
        }
}
```

静态成员在类的所有对象中是共享的，如果不存在其他的初始化语句，在创建第一个对象时，所有的静态数据都会被初始化为0

我们不能把静态成员的初始化放置在类的定义中，但是可以在类的外部通过范围解析运算符::来重新声明静态变量从而对它进行初始化

对于静态成员函数，就可以把函数与类的任何特定对象独立开来，静态成员函数在类对象不存在的情况下与也能被调用，静态成员函数只要使用类名加范围解析运算符::即可访问

**静态成员函数只能访问静态成员数据，其他静态成员函数和类外部其他函数**

静态成员函数有一个类范围，但是它们不能访问类的this指针

```
静态成员与普通成员函数的区别：
- 静态成员函数没有this指针，只能访问静态成员（包括静态成员变量和静态成员函数）
- 普通成员函数有this指针，可以访问类中的任意成员；而静态成员函数没有this指针
```

### 13.继承

```cpp
//基类
class Dad{
    //成员
};
//派生类
class Son : public Dad{
    //成员
}；
//这里是public继承，默认不写关键字时是private继承
```

派生类可以访问基类所有的非私有成员，因此基类成员如果不想被派生类的成员函数访问，应在基类中声明为private

一个派生类继承了所有的基类方法，但下列情况除外：

- 基类的构造函数，析构函数和拷贝构造函数
- 基类的重载运算符
- 基类的友元函数

继承类型：

一共有public，protected或者private三种类型（我们常用的就是public继承）：

- 公有继承：当一个类派生自公有基类时，基类的公有成员也是派生类的公有成员，保护类同理，但是派生类还是访问不到基类的私有成员
- 保护继承：基类公有和保护成员变成派生类的保护成员
- 私有继承：当一个类派生自私有基类，基类的公有和保护成员将成为派生类的私有成员

多继承：多继承即一个子类可以有多个父类，继承多个父类的特性

```cpp
class <派生类名>：<继承方式1><基类1>,<继承方式2><基类2>{
    <派生类类体>
};
```

### 14.多态

当类之间存在层次结构，并且类之间是通过继承关联时，就会用到多态

多态：允许使用基类指针或者引用来调用子类的**重写方法**，从而使得**同一接口**可以表现不同的行为

**多态更具体来说是通过基类指针/引用操作派生类对象时，行为由对象的真实类型决定**

- 虚函数：
  - 在基类中声明一个函数为虚函数，使用关键字virtual
  - 派生类可以重写(override)这个函数
  - 调用虚函数时，会根据对象的实际类型来角决定调用哪个版本的函数
- 动态绑定
  - 也称为晚期绑定，在运行时确定函数调用的具体实现
  - 需要使用指向基类的指针或者引用来调用虚函数，编译器在运行时根据对象的实际类型来决定调用哪个函数
- 纯虚函数
  - 一个包含纯虚函数的类被称为抽象类，它不能被直接实例化
  - 纯虚函数没有函数体，声明时使用 =0
  - 它强制派生类提供具体的实现
- 多态的实现机制
  - 虚函数表：cpp运行时使用虚函数来实现多态，每个包含虚函数的类都有一个虚函数表，表中存储了指向类中所有虚函数的指针
  - 虚函数指针：对象中包含了一个指向该类虚函数表的指针（指向指针表的指针）

注意：

```
- 只有通过基类的指针或者引用调用虚函数时，才会发生多态
- 如果直接使用派生类的对象调用函数，那么调用的是派生类中的版本，而不是基类中的版本
- 多态性需要运行时类型信息，这可能会增加程序的开销
```

### 15.虚函数

虚函数是在基类中使用关键字virtual声明的函数

虚函数允许子类重写它，从而在运行时通过基类指针或者引用调用子类的重写版本，实现动态绑定——在程序任意点可以根据所调用的对象类型来选择调用的函数

特点：

- 在基类中可以有实现：通常虚函数在基类中提供默认实现，但子类可以选择重写
- 动态绑定：在运行根据对象的实际类型调用相应的函数版本
- 可选重写：派生类可以选择性地重写虚函数，但是不是必须

### 16.纯虚函数

纯虚函数是没有实现的虚函数，在基类中用=0来声明

纯虚函数表示基类定义了一个接口，但是具体实现由派生类负责

纯虚函数使得基类变为抽象类，无法实例化

特点：

- 必须在基类中声明为 = 0,表示没有实现，子类必须重写
- 抽象类：包含纯虚函数的类不能直接实例化，必须通过派生类实现所有纯虚函数才能创建对象
- 接口定义：纯虚函数通常用于定义接口，让派生类实现具体行为



这里补充一语法：**基于范围的for循环**

for语句允许简单的范围迭代：

```cpp
int my_array[5]={1,2,3,4,5};
//每个数组元素乘2
for(int& x : my_array){
    x *= 2;
    cout<<x<<endl;
}
//auto类型也是cpp11新特性，用来自动获取变量类型

```

上述中：第一部分定义用来做范围迭代的变量，就像被声明在一般for循环的变量，其作用域只仅限于循环范围中，而在**:**之后的第二区块，代表被迭代的范围

### 17.数据抽象

数据抽象是指：只向外界提供关键信息，并隐藏后台的实现技术，即只表现必要的信息而不呈现细节

数据抽象是一种依赖于接口和实现分离的编程（设计）技术

 数据抽象——向外界提供了大量用于操作对象数据的公共方法，也就是说，外界实际上并不清除类的内部实现

在cpp中，我们使用类来定义我们自己的抽象数据类型（ADT），eg.可以使用**类iostream**的**cout对象**来输出数据到标准输出

访问标签强制抽象：在cpp中，我们使用访问标签来定义类的抽象接口

一个类可以包含0个或者多个访问标签：

- 使用公共标签定义的成员都可以访问该程序的所有部分
- 使用私有标签定义的成员无法访问到使用类的代码

好处：

- 类的内部受到保护，不会因无意的用户级错误导致对象状态受损
- 类实现可能随着时间的推移而发生变化，以便应对不断变化的需求，或者应对那些要求不改变用户级代码的错误报告

设计策略：

```
抽象把代码分离为接口和实现，所以在设计组件时，必须保持接口独立于实现，这样，如果改变底层实现，接口也将保持不变
在这种情况下，不管任何程序使用接口，接口都不会受到影响，只需要将最新的实现重新编译即可
```

### 18.数据封装

数据封装确保了数据的私有性和完整性，防止外部代码对其直接访问和修改

所有的cpp程序都有以下两个基本要素：

- 程序语句——这是程序中执行动作的部分，它们被称为函数
- 程序数据——数据是程序的信息，会受到程序函数的影响

数据封装是一种把数据和操作数据的函数捆绑在一起的机制；数据抽象是一种仅向用户暴露接口而把具体的实现细节隐藏起来的机制

设计策略：

```
通常情况下，我们都会设置类成员状态为私有(private)，除非我们真的需要将其暴露，这样才能保证良好的封装性
这通常应用于数据成员，但它同样适用于所有成员，包括虚函数
```

数据封装的优点：

- 数据隐藏：通过将数据成员声明为私有，防止外部代码直接访问这些数据
- 提高代码可维护性：提供公共方法来访问和修改数据，这使得可以在不影响外部代码的情况下修改类的内部实现
- 增强安全性：防止不合法的数据输入和不当的修改操作
- 实现抽象：提供一种机制，使得用户不需要了解类的内部实现细节，只需要了解如何使用类的公共接口即可

### 19.接口（抽象类）

cpp接口是使用抽象类，抽象类与数据抽象互不混淆，数据抽象是一个把实现细节与相关的数据分离开的概念

如果类中至少有一个函数被声明为纯虚函数，则这个类就是抽象类，纯虚函数是通过在声明中使用"=0"来指定的

```

异常提供了一种转移程序控制权的方式，cpp异常处理涉及到三个关键字:try，catch，throw

double division(int a,int b){

        throw "Division by zero condition!"
    }
    return (a/b);
}

catch块跟在try块后面，用于捕获异常，捕获的异常的类型由catch关键字后面的括号内的异常声明决定的

}
```

匹配模板函数时，当模板函数**只有一个参数类型**时，传入了不同的参数类型，是不进行类型自动转换

```cpp
template <class T>
T myFunction(T arg1 , T arg2){
	cout<<arg1<<""<<arg2<<endl;
    return arg1;
}

//正确的：
myFunction(2,7);

//错误的：
myFunction(2,8.4);
```

### 2.类模板

类模板的定义是定义出一批相似的类，即类的类（类模板），然后由类模板生成不同的类

```cpp
template <class 类型参数1,class 类型参数2,...>//类型参数表
class 类模板名{
    成员函数和成员变量
};
```

用类模板定义对象的写法：

```cpp
类模板名<真实类型参数表> 对象名(构造函数实参表);
```

在深入之前，我们再补充一下对于运算符重载的相关内容

在cpp中可以重新定义或者重载大部分cpp内置的运算符，这样，就可以使用自定义类型的运算

重载运算符是带有特殊名称的函数，函数名是由**关键字operator和其后面要重载的运算符符号构成的**，与其他函数一样，重载运算符有一个返回类型和一个参数列表

```cpp
Box operator + (const Box&);
```

声明加法运算符用于把两个Box对象想加，返回Box对象，大多数的重载运算符可被定义为普通的非成员函数或者被定义为类成员函数，如果我们定义上面的函数为类的非成员函数，那么我们需要为每次操作传递两个参数，如下所示：

```cpp
Box operator + (const Box& , const Box&);
```

```
重载运算符的函数名是：operator 运算符，那么形式参数个数和类型应该是什么：
重载运算符函数的参数数量与该运算符作用的运算对象数量一样多
一元运算符就有一个参数——一元运算符就是类似于运算符计算只要一个参数，因此也只需要一个参数
二元运算符有两个参数——对于二元运算符来说，左侧运算对象传递给第一个参数，而右侧运算对象传递给第二个参数
如果一个运算符函数是成员函数， 则它的第一个（左侧）运算对象绑定到隐式的this指针，因此，成员运算符函数的（显式）参数数量比运算符的运算对象总数少一个
```

需要注意的是：**同一个类模板的两个模板类是不兼容的**

```cpp
Pair<std::string , int> *p;
Pair<std::string , double> a;
p = &a;
```

函数模板作为类模板成员：

当函数模板作为类模板的成员函数时，是可以单独写成函数模板的形式，成员函数模板在使用的时候，编译器才会把函数模板根据传入的函数参数进行实例化

```cpp
//类模板
template <class T>
class A{
	public:
    	template <class T2>
            void Func(T2 t){
            cout<<t;//成员函数模板
        }
};

int main(){
    A<int> a;
    a.Func<char>('k'); //成员函数模板Func被实例化
    a.Func<std::string>("hello");//成员函数模板Func被再次实例化
    
    return 0;
}
```

类模板与友元：

- 函数，类，类的成员函数作为类模板的友元

```cpp
//普通函数
void Func1(){}

//普通类
class A{};

//普通类
class B{
    public:
    void Func(){}; //成员函数
};

//类模板
template <class T>
class Tmp
{
    friend void Func1();//友元函数
    friend class A;//友元类
    friend void B::Func() ;//友元类的成员函数 
}; //任何从Tmp实例化来的类，都有以上三个友元
```

- 函数模板作为类模板的友元

```cpp
//类模板
template <class T1 , class T2>
class Pair
{	
    private:
    	T1 key; //关键字
    	T2 value; //值
    
    public:
    	Pair(T1 k , T2 v):key(k),value(v){};
    
    	//友元函数模板
    	template <class T3,class T4>
        friend ostream& operator << (ostream& o , const Pair<T3,T4>& p);
};

//模板函数
template <class T3 , class T4>
ostream& operator << (ostream& o , const Pair<T3 , T4>& p){
	o<<"("<<p.key<<","<<p.value<<")";
    return o;
}

int main(){
	Pair<std::string , int> student("Tom" , 29);
    Pair<int , double> obj(12 , 3.14);
    
    std::cout<<student<<" "<<obj;
    return 0;
}
```
